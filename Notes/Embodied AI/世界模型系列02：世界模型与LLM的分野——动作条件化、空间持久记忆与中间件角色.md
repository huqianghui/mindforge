# 世界模型系列02：世界模型与 LLM 的分野——动作条件化、空间持久记忆与中间件角色

读完[VLA系列02](VLA系列02：扩散与Transformer在VLA中的分工——动作块并行去噪与闭环重规划.md)和[世界模型系列01](世界模型系列01：世界模型不是一种架构——像素、潜空间、显式3D与物理方程四条实现路线.md)，一个自然的推论是："世界模型和扩散模型一样可以看到所有、不是自回归的，这就是它和 LLM 的区别。"——**这个推论并不成立**，而修正它的过程恰好能把世界模型与 LLM 范式的真正分野讲清楚。

## 一、先修正前提："是否自回归"不是分界线

**视频世界模型恰恰是跨时间自回归的**：它必须先生成第 t 帧，接收 Agent 在第 t 步的动作，才能生成第 t+1 帧——否则就没法"交互"。它和扩散动作头的共同点只是"一段内部双向并行"；而在时间维度上，它甚至比 LLM **更严格地**遵守因果顺序：LLM 生成第 100 个 token 时理论上可以一次性规划全文，世界模型生成第 100 帧时却不能偷看第 101 步 Agent 会做什么——**因为那个动作还没有发生**。

另一头，显式 3D 世界模型（Marble 那类）根本不是序列生成，谈不上自回归与否。

所以"是否自回归"、"能不能看到所有"这些生成机制层面的标签，不是世界模型区别于 LLM 的本质。真正的差别在下面七处。

## 二、七个分野

### 1. 动作条件化——最根本的一条

LLM 的条件只有它自己之前生成的 token 和用户的文本。世界模型在每一步都要接收一个**来自外部 Agent 的动作**作为输入，然后回答"如果这么做，世界会怎样"。这个"如果"是世界模型的定义性特征，LLM 里没有对应物。

Genie 系列走得更远：训练视频里没有动作标注，它用一个"潜在动作模型"（latent action model）从相邻帧的差异里**无监督地推断出"发生了什么动作"**，把动作空间学出来。这在 LLM 里找不到任何类比。

### 2. 它未必是 Transformer，也未必是生成模型

强化学习里最成功的世界模型 Dreamer 系列（V1–V3）用的是循环状态空间模型（RSSM），本质是 RNN，不是 Transformer。LeCun 的 JEPA 更极端：**它不生成任何东西**——只用一个预测器在嵌入空间里预测未来特征，用另一个缓慢更新的目标编码器提供监督，没有重建损失、没有解码器，你没法从它那里得到一张图。JEPA 的立场是"预测像素是浪费，世界模型只需要预测决策相关的抽象量"。

所以"世界模型"这个类别里同时存在 Transformer、RNN、非生成式预测器三种截然不同的形态；而 LLM 几乎是 Transformer 一统天下。

### 3. 输入输出是连续、高维、有空间结构的，tokenizer 是有损的

LLM 的 BPE 分词是无损、离散、一维的。世界模型处理的是像素或点云：连续、每帧几十万维、二维/三维局部相关。所以它必须先用一个**学出来的** VAE 或视频 tokenizer 做**有损压缩**到潜空间再建模——这个压缩器本身就是需要精心设计的模型，压缩多少、丢掉什么直接决定上限。注意力从一维序列变成时空注意力（通常空间、时间分开做以省算力），损失函数从交叉熵变成去噪损失、MSE 或感知损失。

### 4. "记忆"的含义不同：需要空间持久性

LLM 的记忆是 KV cache——记住"前面**说过**什么"。世界模型需要的记忆是**空间性**的：转身 180 度再转回来，桌上的杯子必须还在原处、还是那个杯子。这叫物体持久性（object permanence），是视频世界模型最难的地方，也是[世界模型系列01](世界模型系列01：世界模型不是一种架构——像素、潜空间、显式3D与物理方程四条实现路线.md)里李飞飞批评纯视频路线的核心。

解法有三种，对应三条路线：**拉长上下文硬记**（Genie 3）、**显式空间记忆 / 位姿条件**（RTFM）、**干脆维护显式 3D 表示**（Marble）。LLM 里最接近的问题是长文本一致性，但难度不在一个量级——文本里"前后矛盾"是软约束，物理世界里"物体消失"是硬错误。

### 5. 输出通常不是最终产品，而是被反复调用的中间件

LLM 生成的文本就是交付物。世界模型的输出大多是给别的模块用的：

- **规划**：采样几百条候选动作序列，每条都在世界模型里"演"一遍看结果，挑最好的执行（MPC 式规划）；
- **训练**：策略在想象中跑几百万步，世界模型充当环境；
- **数据合成**：生成多样化场景给 VLA 训练。

因此它对**推理速度**（一次规划要调用几百次，慢一点就没法实时）和**可微性**（要用梯度直接优化策略，就必须端到端可导）的要求与 LLM 完全不同。

### 6. 误差累积的表现形式不同

两者都用 teacher forcing 训练、都有暴露偏差（exposure bias）问题，但表现不同：LLM 是"越写越跑题"或幻觉；世界模型是**几何漂移和物理失真**——几十步之后墙歪了、物体穿模、重力消失。长时程一致性因此成为世界模型的独立研究方向，评价指标也不是困惑度，而是下游任务成功率、多视角一致性、物理合理性。

### 7. 数据的性质不同

互联网文本信息密度极高；视频是"海量但稀释"——一小时视频里对物理理解有用的信息可能只有几句话的量，却要处理几十 GB 像素。这决定了世界模型的算力开销远高于同等"知识量"的语言模型，也是潜空间路线（JEPA、Dreamer）一直有强烈支持者的经济学原因。

## 三、归纳

和 LLM 相比，世界模型的差别不在"是否并行、是否自回归"这种生成机制层面，而在**要回答的问题不同**：

> LLM 回答"接下来最可能**说**什么"；世界模型回答"如果我这么**做**，世界会变成什么样"。

动作条件化、空间持久记忆、连续高维模态、作为规划器内部组件被高频调用——这四条是它和 LLM 范式的本质分野；架构（Transformer 还是 RNN）和生成方式（扩散、自回归还是干脆不生成）都只是在这些约束下的不同工程选择。
