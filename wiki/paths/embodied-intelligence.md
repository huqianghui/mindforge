# 学习路径：具身智能

具身智能是把 agent 放进物理世界：工具从 API 换成电机，环境从文件系统换成真实空间。这条路径先用软件 agent 的经验把整体搭起来，再沿着"空间 → 世界模型 → 生成方法 → 动作 → 落地"一层层往下读，最后回到"这件事在什么场景能先做起来"。

**怎么用**：按站点顺序读，每站对照「算会」自查。这个领域的内容全部来自学习和资料核对，没有自己的真机实验，所以各页置信度大多在 0.65~0.75，读的时候注意 Claim 里"单篇咨询讨论成文""基于公开材料推断"这类边界说明。

**预计总用时**：约 11~13 小时（不含动手实验）。

## 第 1 站 · 全景：具身智能是软件 agent 的物理版

- **读**：[[embodied-ai]]（第 1、2、7 条 Claim）、[[具身智能全景]]、[[机器人系统系列01：硬件形态与生态地图]]
- **前置**：无
- **用时**：约 1.5 小时
- **算会**：
  - 能说出"感知 → 理解 → 规划 → 行动 → 反馈学习"闭环，以及它与软件 agent 至少四组概念的对应（LLM↔VLA、function calling↔技能原语、RAG↔3D 语义地图或世界模型、eval 沙箱↔仿真）
  - 能说出所有工程分化的共同根源：物理世界不可回滚、连续、有噪声、代价高
  - 能用 0.95^20≈36% 解释为什么长链条任务里异常检测与恢复比单点成功率更重要
  - 能解释"形态选择本质上是数据策略选择"：为什么边界清楚的 AGV、机械臂先赚钱，换一种形态最贵的数据资产基本作废

## 第 2 站 · 系统层：分层多频率控制回路

- **读**：[[agent-loop-architecture]]（Claim「agent loop 的物理域实例化」）、[[cybernetics-agent-design]]（Claim「bounded autonomy 与 ODD 安全退出」）、[[机器人系统系列02：Agent循环的物理形态]]、[[机器人系统系列03：角色与实现的分离]]
- **前置**：第 1 站
- **用时**：约 1 小时
- **算会**：
  - 能画出任务层 0.1–1Hz、策略层 10–50Hz、控制层 100–1000Hz 三层嵌套，外加绕开模型的独立安全监视器，并说出频率由什么决定
  - 能说出软件 loop 与具身 loop 的五个本质分野，尤其是"结束信号来自外部验证"和"安全层独立于模型"
  - 能把 bounded autonomy（信息理解 → 人工审核 → 边界内自动执行）对应到软件 agent 的权限模型，并解释 L4 为什么难在 ODD 边界上的安全退出

## 第 3 站 · 空间层：重建管状态，世界模型管状态转移

- **读**：[[spatial-intelligence]]、[[空间智能系列01：3D感知重建与世界模型]]、[[空间智能系列02：显式与隐式空间表达]]；延伸 [[空间智能系列03：3D内容生产的两条路线]]、[[空间智能系列04：神经3D生成的开源版图]]
- **前置**：第 1 站
- **用时**：约 1.5 小时
- **算会**：
  - 能说出空间智能分层栈四层，以及"重建/表征层管状态、世界模型层管状态转移"这句区分
  - 能说出 Perception → Geometry → 3D Semantic Map → Spatial Memory → World Model 五层，以及 3DGS 为什么不是 Spatial Memory
  - 给一个场景（扫地机、仓储导航、自由视角回放），能判断要不要建显式 3D、建到哪一层
  - 能说出神经 3D 生成的三层分工：场景生成铺环境、资产生成出道具、agent 操作引擎组装规则与物理

## 第 4 站 · 认知层：世界模型是一个角色

- **读**：[[world-model]]（第 1、2、3、9 条 Claim）、[[世界模型全景：读懂具身智能的主线]]、[[世界模型系列01：世界模型不是一种架构]]、[[世界模型系列03：世界模型与强化学习的边界]]
- **前置**：第 3 站
- **用时**：约 1.5 小时
- **算会**：
  - 能用 P(s′|s,a) 定义世界模型，并解释"角色不是架构"：同一个 Diffusion Transformer 换输入输出就换角色
  - 能用三要素（Representation、action-conditioned Prediction、Planning）判一个系统算不算世界模型，并说出与 RL 学的函数有什么不同
  - 能说出世界模型与策略、评估器、时间序列预测的三条分界线
  - 能用 Moravec 悖论的三层原因解释 LLM 缺的是"动作之后世界怎么变"

## 第 5 站 · 世界模型的路线、交汇与风险

- **读**：[[world-model]]（第 4、5、6、10、11 条 Claim）、[[世界模型系列02：世界模型与LLM的分野]]、[[世界模型系列04：潜空间路线与V-JEPA-2]]、[[世界模型系列05：像素路线与Cosmos]]；延伸 [[world-model]] 第 8 条（Dream-RSI 的录像回放沙箱，论文初读，0.6）
- **前置**：第 4 站
- **用时**：约 1.5 小时
- **算会**：
  - 能说出世界模型与 LLM 的分野"不在生成机制而在要回答的问题"，以及 V-JEPA 2 与 Qwen3-VL 的对照说明了什么
  - 能说出像素路线与潜空间路线各自的产品是什么（可看的世界 vs 可规划的状态）
  - 能按"范式层 / 表现层 / 用途层"三层看路线，并按"我需要它输出什么"选路线
  - 能说出物理幻觉的四类风险与对策，以及为什么评估器与验证器要和世界模型分开

## 第 6 站 · 方法地基：扩散与 flow matching

- **读**：[[diffusion-model]]、[[VLA系列03：扩散模型基础]]
- **前置**：第 4 站
- **用时**：约 1 小时
- **算会**：
  - 能说出扩散是生成方法不是网络结构，训练学的是修正方向场而不是均值
  - 能逐一解释"高维、连续、多峰"三属性的准确含义，并据此判断一个输出该不该用扩散
  - 能说出扩散与 flow matching 是同一框架的两种参数化，直线路径换来了什么
  - 能解释视频世界模型里"片段内联合浮现、跨片段自回归"这两种因果的区别

## 第 7 站 · 行动层：VLA 的输出架构

- **读**：[[vision-language-action-model]]（第 1、2、3、5 条 Claim）、[[VLA系列01：输出架构演进]]、[[VLA系列04：π0、FAST与Hi-Robot]]
- **前置**：第 2、6 站
- **用时**：约 1.5 小时
- **算会**：
  - 能说出动作输出从离散 token 转向连续动作头的四个原因，哪一个最本质
  - 能说出 π0 双专家怎么交互（共享 self-attention，不是拼接 + MLP，也不是稀疏 MoE），以及 Knowledge Insulation 解决的是什么问题
  - 能解释 FAST 修正了什么：离散路线的瓶颈在分词，代价在推理延迟
  - 能区分"分层是能力结构"与"分层是部署结构"：Hi Robot 双模型 vs π0.5 同一组权重

## 第 8 站 · 动作块与频率口径

- **读**：[[action-chunking]]、[[vision-language-action-model]]（第 6 条 Claim「评估 VLA 声明的维度清单」）、[[VLA系列02：扩散与Transformer的分工]]、[[VLA系列05：π0.5与实时分块]]
- **前置**：第 7 站
- **用时**：约 1 小时
- **算会**：
  - 能解释"动作有先后因果，为什么还能并行生成"：块内并行去噪，块间闭环重规划承担因果
  - 能说出 RTC 怎么把块边界的停顿转成 inpainting，以及它只适用于哪类策略
  - 能把块生成延迟、串行推理调用速率、控制执行频率、重规划频率四个口径分开，各举 π0 的数字
  - 拿到一条 VLA 宣传，能列出至少四个要追问的维度

## 第 9 站 · 落地：数据、自动驾驶与分层选型

- **读**：[[embodied-ai]]（第 3、4、5、6 条 Claim）、[[vision-language-action-model]]（第 4、7 条 Claim）、[[world-model]]（第 7 条 Claim）、[[落地实践系列01：数据飞轮与VITRA]]、[[落地实践系列02：自动驾驶与世界模型]]、[[落地实践系列03：分层选型决策]]
- **前置**：第 5、8 站
- **用时**：约 1.5 小时
- **算会**：
  - 能说出遥操作、仿真合成、人类视频转化三条数据来源各自的代价，以及为什么必须组合使用
  - 能解释 π0.5 的开放世界泛化靠的是数据组合（97.6% 预训练数据来自非目标平台），以及 RECAP 的"从经验学习"不是什么
  - 能说出 L2 量产数据飞轮的裂缝在哪里，为什么要靠世界模型、仿真加 RL 补
  - 给一个"给机器人加 X 能力"的需求，能按"定层 → 拆线 → 接栈"给出入场级别，并提醒许可条款这道硬门槛

## 前沿站 · 正在发生的变化

知识差距报告到目前为止还没有追踪过具身主题（这条路径建立时在 `topics.yml` 新增了 `embodied-ai`，下一期开始跟踪）。下面几条是 wiki 里已经记下、但还在变化中的结论，「算会」统一是：**能说出它改变了上面哪一站的哪条结论**。

- **像素路线开始直接输出动作**（Cosmos 3 全模态）→ 影响第 5、7 站：世界模型与 VLA 的边界在变模糊，"同一网络换输入输出就换角色"又多一个样本
- **VLA 从模仿转向真机经验 RL**（π0.6 / π*0.6 的 RECAP）→ 影响第 9 站：数据飞轮里的反馈信号从哪来
- **神经 3D 生成进入开源**（HY-World 2.0、TRELLIS.2）→ 影响第 3、9 站：仿真环境能不能批量生成，许可条款是否允许
- **路线串联为工序**（HY-World 2.0 中间用视频、产物是 3D）→ 影响第 4 站：四条路线不是互斥阵营

## 毕业标准

给一个具体的机器人需求（仓储分拣、家庭整理、巡检、人形演示），能在 15 分钟内说出：落在哪一层、入场级别选传统方案、模仿学习、VLA 还是世界模型，数据从哪来，评估时要追问哪几个维度，以及安全边界放在哪里。

## 这条路径暴露的缺口

- **没有一手实验**：全部内容来自学习与资料核对，各页都没有 Practice 记录；最便宜的验证是用 LeRobot 跑一次 ACT 模仿学习，能直接检验第 9 站"Level 1 几十条 demo"的入场判断
- **方法页为零**：分层选型的"定层 → 拆线 → 接栈"三步模板只是一条 Claim，素材够的话可以抽成方法页
- **外部信号空白**：知识差距报告过去没有扫这个领域，arXiv 与 HF 的具身信号要从下一期开始补
