# Embodied AI（具身智能）

## 摘要

具身智能 = **让 Agent 拥有"身体"，在物理世界里完成 感知 → 理解 → 规划 → 行动 → 反馈学习 的闭环**。它与软件 Agent 是同一套逻辑——只是"工具"从 API 变成电机、"环境"从文件系统变成真实空间；所有工程分化的共同根源是：**物理世界不可回滚、连续、有噪声、代价高**。行业的核心判断：AI 能力分水岭不在"会不会说"而在"能不能做"——从建议层进入执行回路是跃迁而非线性改善，软件 Agent 已在数字世界完成这次跃迁，具身智能是同一逻辑在物理世界的延伸。

本页是具身智能域的锚点页，镜像《具身智能全景》总导读的五条主线结构：**空间层**（[[spatial-intelligence]]）→ **认知层**（[[world-model]]）→ **系统层**（分层控制回路与角色分解）→ **行动层**（[[vision-language-action-model]]，含 [[action-chunking]]、[[diffusion-model]] 方法地基）→ **落地层**（数据飞轮、自动驾驶交汇、分层选型）。源头是 2026-09-17 起与 AI 的多轮讨论沉淀成的 21 篇系列文章（Notes/Embodied AI/）。

## Claims

### Claim: 具身智能的大部分工程问题在软件 Agent 里都有同构版本，差异全部指向"物理世界不可回滚、连续、有噪声、代价高"这一个根源

- **来源**：[[具身智能全景：从LLM、Agent、RAG到物理世界闭环]]
- **首次出现**：2026-09-17
- **最近更新**：2026-09-25
- **置信度**：0.7
- **状态**：active

> 概念映射表逐行对应：LLM↔VLA（动作作为一种模态，但连续、高频、错了不能 Ctrl+Z）；Function calling↔技能原语（"工具"成功率不是 100%，需闭环纠错）；RAG 知识库↔3D 语义地图/世界模型（知识是空间的、动态的）；Planner+Executor↔高层任务规划+低层动作策略（executor 从确定性代码换成概率性控制模型）；Eval 沙箱↔仿真/视频世界模型（sim-to-real gap）；RLHF↔遥操作纠正后的持续学习（反馈来自物理世界，采集贵）；预训练语料↔人类第一视角视频/遥操作轨迹（真机数据是行业最大瓶颈）；Guardrails↔bounded autonomy。行业共同瓶颈五条：真机数据贵、长链条错误累积（0.95^20≈36%，异常检测与恢复比单点成功率更重要）、实验室泛化≠现场泛化、安全与责任边界、经济性（工业先于家庭跑通的原因）。

### Claim: 空间智能是具身智能的认知底座，具身智能是空间智能最重要的落地载体

- **来源**：[[具身智能全景：从LLM、Agent、RAG到物理世界闭环]]
- **首次出现**：2026-09-17
- **最近更新**：2026-09-25
- **置信度**：0.7
- **状态**：active

> 闭环五段中，感知、理解、规划三段的核心能力正是空间智能（李飞飞 2024 提出，强调"看到就能理解"）；行动与反馈学习一段是具身智能补上的（强调有身体、"交互中学习"）。李飞飞在 World Labs 收购机器人仿真公司 SceniX 后明确表达：机器人是空间智能的最佳物理载体。

### Claim: 数据策略本身就是技术路线——遥操作/仿真合成/人类视频转化三条数据来源与 LLM 的"人工标注/合成数据/网络爬取"三角同构，必须组合使用

- **来源**：[[具身智能全景：从LLM、Agent、RAG到物理世界闭环]]、[[落地实践系列01：数据飞轮与VITRA——把人类视频变成机器人的互联网语料]]
- **首次出现**：2026-09-17
- **最近更新**：2026-09-25
- **置信度**：0.7
- **状态**：active

> 机器人领域没有互联网文本那样的现成语料：遥操作质量最高成本也最高；仿真合成规模大但有 sim-to-real gap；人类视频转化（VITRA：把人手当作一种机器人末端执行器，百万级 episode 转成 VLA 预训练语料，未见物体约 70% 零样本成功率）是"互联网语料"路线。VITRA 的准确定位是一套可复用的数据工程方法而非模型。

### Claim: 物理世界的落地形态普遍是 bounded autonomy，与软件 Agent 权限模型（read-only → approval → auto-accept）完全同构；L4 自动驾驶的"知道自己不知道"是其工程化极致

- **来源**：[[具身智能全景：从LLM、Agent、RAG到物理世界闭环]]、[[落地实践系列02：自动驾驶与世界模型的路线交汇——传感器之争、数据飞轮与世界基础模型]]
- **首次出现**：2026-09-17
- **最近更新**：2026-09-25
- **置信度**：0.7
- **状态**：active

> 物理世界里"模型幻觉"的代价是碰撞和损坏，所以落地顺序普遍是：先信息理解与分析建议 → 保留人工审核 → 明确边界内自动执行。自动驾驶侧的对应物：L4 真正难的不是"开得好"而是 ODD 边界上的安全退出——perception confidence 低于阈值时主动降级/fallback/Minimal Risk Maneuver；SAE 分级是责任坐标系而非智能坐标系（L2→L3 跳变是责任转移）。

### Claim: 入场点由能力级别决定而非模型新旧——Level 0 传统方案 → L1 模仿学习（ACT，几十条 demo）→ L2 VLA → L3 世界模型，升级触发条件是任务泛化需求与数据量

- **来源**：[[落地实践系列03：分层选型决策——世界模型、VLA与空间智能的技术栈选择指南]]
- **首次出现**：2026-09-20
- **最近更新**：2026-09-25
- **置信度**：0.65
- **状态**：active

> 具身智能是分层栈不是单一模型：World Model（Cosmos 3）、VLA（GR00T/π0/OpenVLA）、Robot Learning（LeRobot——"最容易被低估的一环"，LeRobotDataset 标准化 episode 格式=数据资产化，VLA 最核心资产是 robot trajectory data 而非模型）、3D/Spatial、Simulation（Isaac）各答各的问题，选型按层进行。任何"给机器人加 X 能力"的需求都可套用"定层 → 拆线 → 接栈"三步决策模板。注意：单篇咨询讨论成文、无自身 POC 实践验证。

### Claim: 开放权重 ≠ 随便用——许可条款是具身仿真训练的硬门槛

- **来源**：[[空间智能系列04：神经3D生成的开源版图——HY-World 2.0可探索世界、TRELLIS.2高保真资产与Marble对照]]
- **首次出现**：2026-09-21
- **最近更新**：2026-09-25
- **置信度**：0.75
- **状态**：active

> HY-World 2.0 的 Tencent Community License 三条硬约束：地域排除欧盟/英国/韩国；月活超 1 亿需另行授权；**不得用该模型及其输出改进其他 AI 模型**——"用它批量生成仿真环境训练机器人策略"是否落入禁区，上生产前必须逐字对照条款确认。对照 TRELLIS.2 模型与代码 MIT 无障碍。开源阵营补上的是"拿得到权重、进得了自己的 pipeline"，不自动等于"随便商用、随便训练"（基于许可全文核对，未实际部署验证）。
