# One Person Team

## 摘要

AI 正在重新定义技术角色的能力边界，一个掌握 AI 编排能力的架构师可以借助工具链独立完成之前需要多人团队协作的工作。核心技能从手动编码转变为 Prompt Engineering / AI Orchestration / Skill-Flow Design / Context Engineering。

### Claim: 团队形态收敛为 2-3 人精英组 + AI Agent 编队——协调通过 Spec 不通过会议

- **来源**：[[FDE职业进化论——AI时代前线部署工程师的个人突围与团队重构]]
- **首次出现**：2026-05-30
- **最近更新**：2026-08-04
- **置信度**：0.7
- **状态**：active

> FDE 团队重构的落点：不是"一个人"而是"2-3 人精英组，每人指挥一支 AI Agent 编队"——人数压到最低是因为人际协调成本随人数平方增长，而 Agent 编队的协调成本近乎线性。协调机制随之改变：人与人之间通过 Spec（问题定义、约束、验收标准落成文字）对齐，不通过会议——Spec 同时就是喂给各自 Agent 编队的输入，写一次两用。这把 one-person-team 从"个体生产力放大"升级为"最小作战单元设计"：单人是下限形态，2-3 人组是对抗单点风险（休假、盲区、判断偏差）的稳定形态。
