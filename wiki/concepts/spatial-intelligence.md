# Spatial Intelligence（空间智能）

## 摘要

空间智能（李飞飞 2024 提出）指 AI 感知、理解、推理三维世界的能力，强调"看到就能理解"。它被单独提出为一个方向的原因：3D/空间拓扑理解目前仍是大模型的明显短板——语言模型对"左边第二个抽屉"、"门后面"这类空间关系的推理远弱于文本关系推理。

结构上它是一个**分层栈**：① 感知与重建（传感器数据→3D 状态 s_t：VGGT/3DGS/SAM/SLAM）→ ② 3D 表征与空间推理（3D 语义地图、场景记忆）→ ③ 世界模型（状态转移 P(s_{t+1}|s_t,a_t)）→ ④ 规划与行动（VLA/MPC）。一句话区分：**重建/表征层管"状态"，世界模型层管"状态转移"**。日常语境的"空间智能"多指重建层；产业积累集中在重建层（管线成熟）与行动层（VLA 热点），**中间的世界模型层反而是栈里最薄的一层**。

## Claims

### Claim: 空间智能分层栈——重建层回答"世界现在什么样"，世界模型层回答"动作之下会怎么变"，两层常被混为一谈

- **来源**：[[空间智能系列01：3D感知重建与世界模型的关系——状态与状态转移的空间智能分层栈]]
- **首次出现**：2026-09-17
- **最近更新**：2026-09-25
- **置信度**：0.7
- **状态**：active

> 家庭场景例子：固定摄像头+移动机器人融合出的家庭 3D 语义地图属重建层（"沙发在哪、门开着没"）；在这张地图上预测"猫下一秒往哪跑、路径两秒后会不会被人挡住"才是世界模型层。TRELLIS 这类生成式 3D 不是世界模型——它为仿真世界提供"内容"，与世界模型的关系分三层：重建提供状态、生成提供内容、边界正在模糊。VGGT 的准确定位是 3D State Encoder，不是世界模型。

### Claim: 从几何到记忆隔着两层——3DGS 不是 Spatial Memory；Spatial Memory 不是一张地图而是一个数据库

- **来源**：[[空间智能系列02：显式与隐式空间表达——VGGT、3DGS到空间记忆的五层抽象与选用边界]]
- **首次出现**：2026-09-20
- **最近更新**：2026-09-25
- **置信度**：0.7
- **状态**：active

> 五层抽象链：Perception → Geometry → 3D Semantic Map → Spatial Memory → World Model。VGGT 管"看懂"（一次前馈替代 COLMAP 优化管线，从图像恢复 pose/depth/point map），3DGS 管"存下并重现"（显式 Gaussian 集合+实时渲染），两者可组官方管线（VGGT 做 geometry init）但都只处理"现在"。几何之上先加语义（3D Semantic Map/Scene Graph：对象+位姿+关系），再加时间与生命周期（Spatial Memory：可查询、可更新的 3D+语义+时间数据库，支持 `objects where class=camera` 式空间查询），World Model 消费的 spatial state 才从这里产出。

### Claim: 选用边界——需要 XYZ 才建显式 3D，且建到需求对应的那一层为止；显式与隐式是平行路线不是上下游

- **来源**：[[空间智能系列02：显式与隐式空间表达——VGGT、3DGS到空间记忆的五层抽象与选用边界]]
- **首次出现**：2026-09-20
- **最近更新**：2026-09-25
- **置信度**：0.7
- **状态**：active

> 需要精确测量、多相机统一坐标、导航、长期记忆、空间查询五类场景才建显式 3D；需要高保真自由视角渲染才上 3DGS——扫地机器人一张 occupancy grid 就够，别上五百万个 Gaussian。隐式路线（Cosmos 直接吃视频、在 latent 里学空间与动力学）不是性能妥协而是任务不同：隐式 3D 有空间理解但没有 XYZ。产品路线是 Hybrid：一致性交给显式表示、动态交给学习。

### Claim: 神经 3D 生成的开源版图是三层分工——场景生成铺环境、资产生成出道具、Agent 操作引擎组装规则与物理

- **来源**：[[空间智能系列04：神经3D生成的开源版图——HY-World 2.0可探索世界、TRELLIS.2高保真资产与Marble对照]]、[[空间智能系列03：3D内容生产的两条路线——Agent操作Blender与神经3D生成的分工]]
- **首次出现**：2026-09-21
- **最近更新**：2026-09-25
- **置信度**：0.65
- **状态**：active

> 世界层 HY-World 2.0（开放权重、对标 Marble 的"一张图变可探索 3D 世界"能力定义——注意 Marble 是平台非模型，只能比"平台能力定义"层次）+ 资产层 TRELLIS.2（MIT，接近生产资产精度）+ 引擎层 Agent 操作 Blender/UE5（作者自注"基于能力分析、非已验证集成"）。"可参数化编辑的工程资产"仍归 Agent+传统工具路线——TRELLIS.2 附录自认不编码部件级语义。3D 内容生产两条路线（指挥工具造 vs 直接生成）的分工：离线生产 vs 运行时感知。
